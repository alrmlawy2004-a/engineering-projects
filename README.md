# Engineering Projects

I am Alaa Salim Al Ramlawi. This collection brings together my projects and exercises in intelligent systems and computer engineering. Each folder has its own setup instructions and limitations.

- [Java Console Applications](java-applications/README.md): I explore file-based workflows and data structures through three console applications: a clinic system, a bank exercise, and a customer waiting queue.
- [Phone Directory](phone-directory/README.md): I built a menu-driven contact directory with add, list, search, edit and delete operations, including local phone and identifier validation.
- [Machine Learning Studies](machine-learning/README.md): I compare logistic regression and decision trees for telecom customer churn, and PCA/LDA representations with support vector classification for human activity recognition.
- [Pattern Recognition Studies](pattern-recognition/README.md): I compare linear SVM and XGBoost models for binary wine quality and explore distributions and statistical tests in the Palmer Penguins dataset.
- [Data Systems Experiments](data-systems/README.md): I explore file-format tradeoffs, Parquet partitioning, replicated storage planning, and a simulated HDFS block-loss model.
- [Relational Database Exercises](databases/README.md): I model an online store with categories, products, customers, orders and order items, alongside smaller student, library and healthcare query exercises.
- [Web Interface Studies](web-interfaces/README.md): I practice HTML and CSS with a game-store catalog, a product landing page, an Avatar-themed layout, a creative workspace page and a user interface exercise.
- [Algorithms and Data Structures](algorithms/README.md): I practice account modeling, randomized treasure/bag operations, and stack-based balanced-parenthesis checking in separate Java exercises.
- [Computer Network Design](network-design/README.md): I created a Cisco Packet Tracer network-design project.

## Working with the collection

These projects span different environments. There is no shared build command. Read the relevant project README before running code. Use fictional records for the console applications and isolated development databases for SQL. Datasets needed by the notebooks are described in their READMEs.
