# Phone Directory

I built a menu-driven contact directory with add, list, search, edit and delete operations, including local phone and identifier validation.

## Technologies

Python standard library.

## Files

- `phone_directory.py`

## Run

Set `DIRECTORY_USERNAME` and `DIRECTORY_PASSWORD` in your environment, then run `python phone_directory.py`. On PowerShell: `$env:DIRECTORY_USERNAME="demo"; $env:DIRECTORY_PASSWORD="your-demo-password"; python phone_directory.py`.

## Scope and limitations

Records are held in memory and disappear when the process ends. This is a console exercise; environment-configured demo credentials do not provide production authentication. Use fictional data.
